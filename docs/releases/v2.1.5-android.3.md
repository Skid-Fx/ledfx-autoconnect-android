# LedFx AutoConnect for Android v2.1.5-android.3

SkidFx Android release based on the LedFx 2.1.5 engine.

## Added

- **Manual WLED discovery in Add Device**: tap the magnifying glass beside the WLED IP address field to scan available Wi-Fi and Android hotspot networks.
- View discovered devices' WLED name, IP address, and firmware version, select a controller, and fill in its IP address without prematurely creating a device.
- Show controllers already configured in LedFx as **Already Added** (disabled).
- Display discovery scan progress, network ranges, and errors; support canceling an active scan.

## Improved

- Reset Add Device form when starting another new device; editing an existing device still loads its saved configuration.
- Place the WLED search control outside the IP address field.
- Improve portrait and landscape Dashboard layout: responsive circular controls, centered Android notice, and landscape floating-button placement.
- Identify the build as **SkidFx Alpha Build 2.1.5-android.3** with concise unofficial-build notice.
- Redirect the Android **NEW UPDATE** indicator to published SkidFx GitHub releases; display it only for a newer, comparable release with an APK asset. The upstream LedFx update indicator remains for non-Android clients.

## Build and maintenance

- Automate pinned Node.js, Yarn, frontend dependency installation, TypeScript checks, React Android compilation, compiled asset synchronization, and cached WLED API sync.
- Expand `BUILDING.md` to document the full Python/Java/Android/Node toolchain, pinned p4a toolchain, custom recipes, script inventory, APK verification, submodule publishing order, and wireless debugging.

## Tested

- Manual WLED discovery on an Android hotspot; select and add a controller; already-added controllers disabled; adding further devices supported.
- Phone installation using wireless ADB; working portrait layout; functional Android app startup.
- Android Python bundles contain the new WLED API in both `armeabi-v7a` and `arm64-v8a`.

## Notes

- The app's Android package is `com.skidfx.ledfxautoconnect`.
- Existing `v2.1.5-android.2` remains available for rollback.
- This is an unofficial build not supported by the upstream LedFx team.
